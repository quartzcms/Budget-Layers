# Budget-Layers

<p>The Budget-Layers software is used to build and manage a budget and calculate the future expense or profit made using a list of expenses and adding a daily, weekly, monthly or yearly schedule. The app let you publish, delete, update an expenses, plan, container modules and view a full list of profit and expense predictions based on the saved modules.</p>

<p>The list of feature include:</p>

<ul>
	<li>Container module with tags</li>
	<li>Expense section</li>
	<li>Plan module</li>
	<li>Full list of future gain and expense</li>
	<li>User section</li>
	<li>Plugin section</li>
</ul>

<p>These server requirements are needed for all versions:</p>

<ul>
	<li>MySQL: 5.5 or higher</li>
	<li>Apache: 2.2 or higher</li>
	<li>PHP: 7.0 to 7.4</li>
	<li>Storage: 50 MB or higher</li>
	<li>ZIP Archive Installed</li>
	<li>MEMORY_LIMIT: 128 MB or higher</li>
	<li>VPS or shared hosting</li>
</ul>

<p>The database can be installed from the SQL file budget_layers.sql</p>

<p>To configure the database credentials open the config.php file and update the variables.</p>
